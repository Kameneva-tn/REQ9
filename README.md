# REQ9 — Amino Code · прототип сайту v2 (Lab)

Статичний сайт без збірки: відкрийте `index.html` або розмістіть вміст папки в корені домену.

| Файл | Сторінка |
|---|---|
| `index.html` | 01 Головна |
| `product.html` | 02 Продукт |
| `science.html` | 03 Наука і технології |
| `distributors.html` | 04 Дистриб’ютори |
| `about.html` | 05 Про бренд і контакти |

`assets/` — зображення, стилі (`req9-lab.css`, `req9-aelab.css`), анімації (`req9-lab.js`) і міні-рантайм `dc-lite.js`.
Шрифти: Onest + Roboto Mono (Google Fonts). Outfit — тільки в логотипі.

Прототип: форми не надсилають дані, контакти дистриб’юторів — плейсхолдери. Сторінки мають `noindex`.
